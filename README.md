
# Online Retail Data Analysis

## Project Overview
This project analyses online retail transaction data
using Python to understand product performance and
monthly sales trends.

## Objectives
- Clean and prepare retail transaction data.
- Calculate transaction revenue.
- Identify top-performing products.
- Analyse monthly revenue trends.
- Develop evidence-based business insights.

## Tools Used
- Python
- Pandas
- Matplotlib
- Google Colab

## Project Workflow
1. Load the retail dataset.
2. Inspect missing values and duplicates.
3. Clean transaction records.
4. Calculate revenue.
5. Analyse product performance.
6. Visualise monthly sales trends.
7. Summarise business findings.

## Key Findings
See the notebook for the actual results and
three findings based on the analysed data.

## How to Run
1. Open the notebook in Google Colab.
2. Download the dataset from the UCI repository.
3. Upload the dataset to the Colab session.
4. Run the notebook cells in order.

## Dataset
UCI Online Retail Dataset:
https://archive.ics.uci.edu/dataset/352/online+retail

## Limitations
The analysis excludes non-positive quantities
and may not represent net revenue after returns.
